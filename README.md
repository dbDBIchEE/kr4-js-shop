## Инструкция по запуску
Так как проект использует ES-модули (import/export), его нельзя открывать просто двойным кликом по index.html. Запустите локальный сервер в терминале:
npx serve
Затем откройте в браузере адрес, который будет указан в терминале (например, http://localhost:3000).

## Структура JavaScript-файлов
- data.js — массив из 8 товаров с единой структурой (id, title, category, price, oldPrice, isAvailable и т.д.).
- catalog.js — логика каталога: фильтрация, поиск, сортировка, генерация карточек через DOM.
- cart.js — корзина (выезжающая панель), добавление/удаление, промокод и синхронизация с localStorage.
- forms.js — валидация форм, логика шагов модального окна (wizard), маска телефона.
- modal.js — управление модальными окнами (открытие/закрытие, фокус, Esc, ловушка табуляции).
- menu.js — работа мобильного бургер-меню.
- main.js — точка входа: инициализация модулей и глобальные обработчики.

## Реализованный базовый функционал
1. Каталог: Карточки товаров генерируются через document.createElement() (без innerHTML).
2. Поиск и фильтрация: Реализован поиск по названию/описанию (событие input), фильтр по категориям и сортировка по цене (события change). Исходный массив не мутирует (сортируется копия).
3. Безопасность: Все данные выводятся через textContent. Пользовательский ввод не интерпретируется как HTML.
4. Состояние: При отсутствии результатов поиска выводится пустое состояние.
5. Доступность (A11y): Видимый фокус (:focus-visible), aria-invalid при ошибках валидации, скрытые элементы исключены из Tab-навигации.

## Самостоятельные доработки (Повышенный уровень)
1. Корзина: Выезжающая панель (Sidebar). Реализовано добавление, удаление и пересчет итоговой суммы.
2. localStorage: Корзина сохраняется в память браузера и не пропадает при перезагрузке страницы.
3. Промокод: В корзине работает промокод SPORT10, который дает скидку 10% на весь заказ. Пересчет суммы происходит динамически (метод reduce).
4. Многошаговая форма (Wizard): Заказ оформляется в 3 шага с визуальным индикатором прогресса. Реализован подсчет доставки (5% от суммы) и вывод итоговой сводки заказа.
5. Пользовательский опыт (UX): Маска ввода телефона (форматирование в +7 (999) 123-45-67). Автопереход курсора при вводе @ в поле Email. Кнопки недоступных товаров блокируются (disabled). Интерактивная кнопка "Наверх".
